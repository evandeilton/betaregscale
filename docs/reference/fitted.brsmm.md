# Fitted values from a brsmm model

Fitted values from a brsmm model

## Usage

``` r
# S3 method for class 'brsmm'
fitted(object, type = c("mu", "phi"), ...)
```

## Arguments

- object:

  A fitted `"brsmm"` object.

- type:

  Character: `"mu"` (default) or `"phi"`.

- ...:

  Currently ignored.

## Value

Numeric vector.
