# Variance-covariance matrix for brsmm coefficients

Variance-covariance matrix for brsmm coefficients

## Usage

``` r
# S3 method for class 'brsmm'
vcov(object, model = c("full", "mean", "precision", "random"), ...)
```

## Arguments

- object:

  A fitted `"brsmm"` object.

- model:

  Character: `"full"`, `"mean"`, `"precision"`, or `"random"`.

- ...:

  Ignored.

## Value

Numeric matrix.
