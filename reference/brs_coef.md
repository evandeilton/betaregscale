# Internal coefficient table (deprecated, use brs_est() or summary())

Internal coefficient table (deprecated, use brs_est() or summary())

## Usage

``` r
brs_coef(fit, alpha = 0.05)
```

## Arguments

- fit:

  A fitted `"brs"` object.

- alpha:

  Significance level.

## Value

A list with `est` and `gof`.
