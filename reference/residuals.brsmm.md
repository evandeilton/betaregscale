# Residuals from a brsmm model

Residuals from a brsmm model

## Usage

``` r
# S3 method for class 'brsmm'
residuals(object, type = c("response", "pearson"), ...)
```

## Arguments

- object:

  A fitted `"brsmm"` object.

- type:

  Character: `"response"` (default) or `"pearson"`.

- ...:

  Ignored.

## Value

Numeric vector.
